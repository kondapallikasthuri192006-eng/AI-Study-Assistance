# 🤖 AI Study Assistant

AI Study Assistant is a GenAI-based application designed to help students learn faster and prepare for exams and interviews.

## ✨ Features

- 💬 Ask questions and get simple explanations
- 📝 Generate short study notes
- 📄 Summarize long text
- ❓ Generate MCQs with answers
- 🎯 Generate interview questions
- 📚 Student-friendly explanations

## 🛠️ Technologies Used

- Python
- OpenAI API
- Streamlit
- GitHub
